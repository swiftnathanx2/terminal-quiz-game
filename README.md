# 🏷 Terminal Quiz

A Terminal based quiz app that asks users questions on Geography and Techonology, it has a practice mode and highscore system.

## 📌 Problem Statement

This quiz provides students with much needed information about Geography and current developments in Technology. This application gamifies learning.

## 🎯 Project Goals

- Allows users to answer questions
  -Allows users to practice through the practice mode system
  -Provides a highscore system.
  -Shuffles questions

## 🛠 Tech Stack

**Programming Language**
Bash

**Bash Commands**
-awk
-mapfile
-functions
-shuf

## 🖥 Features

-Practice Mode
-Highscore System
